# 使用规范

图即用于页面开发与接口联调中的占位。按下列方式使用，有助于加载更快、画面稳定，也更不容易触发限额。

限额如有调整，会在文档中公布。

---

## 推荐用法

| 场景 | 方式 |
| ------ | ------ |
| 占位图、头像、场景图、照片 | 在页面中用 `<img>` 直接引用 CDN URL |
| 需要画面稳定 | 使用 `/seed/...`，或头像固定 `style` + 标识，或照片带 `seed` |
| Mock JSON | 请求一次后在本地缓存，不要在渲染循环中反复请求 |
| 位图 | 优先 SVG；仅在小程序等必须位图的场景使用 WebP / PNG |

```html
<img src="https://cdn.devimg.cn/avatar/devimg/Luna/128?text=0" alt="avatar" />
<img src="https://cdn.devimg.cn/seed/demo/800/600" alt="seed" />
```

---

## 不推荐的用法

| 行为 | 说明 |
| ------ | ------ |
| 由服务端统一代理全部图片请求 | 浏览器无法缓存图片，页面更慢，也更容易触发按 IP 计算的限额 |
| 为每个用户生成从不复用的随机 URL | 无法命中缓存，同一页面重复打开也会重新下载 |
| 对 `/mock/*` 高频轮询 | 每次都会重新请求，拖慢联调，也容易触发限额 |
| 单页同时加载大量互不相同的占位 URL | 首屏请求过多，加载变慢，也可能触发限额 |
| 爬取、压测、批量下载图库 | 超出占位与联调用途 |

码形接口输出的图案不可扫描，请勿用于支付、登录或物流等真实扫码场景。见 [码形占位 API](/api/qr)。

---

## 缓存

浏览器会缓存同一 URL。需要画面始终不变时，请使用固定参数（`seed`，或头像的 `style` + 标识）。

| 类型 | 说明 |
| ------ | ------ |
| 头像、seed 占位、码形、带 `seed` 的照片 | 同一链接画面固定，适合列表与界面对照 |
| 未指定颜色的色块占位、无 `seed` 的照片 | 画面可能变化，不适合当作固定素材 |
| Mock 数据 | 请求一次后请在本地保存，不要反复拉取 |

---

## 限额

| 类型 | 限额 |
| ------ | ------ |
| 默认（SVG、JSON 等） | **1000 次 / 分钟 / IP** |
| WebP / PNG | **60 次 / 分钟 / IP**（请优先使用 SVG） |

超出时接口返回 HTTP `429`。请尽量复用同一 URL，避免为每次展示生成新地址。
