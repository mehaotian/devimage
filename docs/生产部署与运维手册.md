> 域名：`cdn.devimg.cn`（API/CDN）· `devimg.cn`（文档站）

> 关联：[腾讯云 COS 部署指南](./腾讯云COS部署指南.md) · 用户文档 [部署指南](../apps/docs/guide/deployment.md)

## 1. 正确发布流程（避免「没提交就 scp」）

```text
本地改代码 → git commit → git push
  → 服务器 cd /home/ht/devimg
  → pnpm deploy          # pull + build + pm2 reload + health
```

**不要**在未 push 的情况下直接 `scp` 覆盖服务器文件；否则下次 `git pull` 会冲突或丢改动。

---

## 2. 域名与证书

| 入口 | 用途 | HTTPS |
| ------ | ------ | ------ |
| `https://cdn.devimg.cn` | 占位图 / Mock / Swagger | 腾讯云 CDN → HTTPS 配置（边缘证书） |
| `https://devimg.cn` | VitePress 文档 | 源站 Let's Encrypt（certbot） |

CDN **回源**建议：`HTTP` + 源站 IP + 端口 `80` + 回源 HOST `cdn.devimg.cn`。  
用户访问仍用 **HTTPS**。

API 进程监听 **`127.0.0.1:3010`**（避开同机其它项目的 3000）。

## 3. package.json 快捷命令

在服务器仓库根目录执行：

| 命令 | 作用 |
| ------ | ------ |
| `pnpm deploy` | **一键**：pull → install/build → 启动/热更 → 健康检查 |
| `pnpm deploy:pull` | 仅 `git pull --ff-only` |
| `pnpm deploy:build` | `pnpm install` + 生产 URL 构建 API/文档 |
| `pnpm deploy:start` | PM2 首次启动或 `reload` |
| `pnpm deploy:stop` | 停止 API |
| `pnpm deploy:restart` | 重启 API |
| `pnpm deploy:status` | 查看 PM2 状态 |
| `pnpm deploy:logs` | 跟踪日志 |
| `pnpm deploy:health` | 本机探测 `/health` 与占位图 |
| `pnpm deploy:remote` | **本机** SSH 到服务器执行 `pnpm deploy` |

脚本目录：`deploy/scripts/`。PM2 配置：`deploy/ecosystem.config.cjs`。

### 本机远程一键部署

```bash
cp deploy/.env.deploy.example deploy/.env.deploy
# 编辑 DEPLOY_SSH / DEPLOY_PATH

pnpm deploy:remote
# 或只远程重启：
# bash deploy/scripts/remote.sh deploy:restart
```

## 4. 环境变量

### API（`apps/api/.env`，勿提交）

| 变量 | 生产建议 |
| ------ | ------ |
| `PORT` | `3010` |
| `DEVIMAGE_PUBLIC_URL` | `https://cdn.devimg.cn` |
| `COS_CDN_DOMAIN` | `https://cdn.devimg.cn` |
| COS / CAM 密钥 | 按需填写 |

### 文档构建（`deploy/.env.deploy` 可选）

| 变量 | 默认 |
| ------ | ------ |
| `VITE_API_BASE` | `https://cdn.devimg.cn` |
| `VITE_DOCS_ORIGIN` | `https://devimg.cn` |

Markdown 源文件仍写 `localhost`；**生产 build** 时替换为上述域名。

## 5. Nginx / Certbot

参考配置：`deploy/nginx/devimg.conf`。

```bash
sudo cp /home/ht/devimg/deploy/nginx/devimg.conf /etc/nginx/sites-available/devimg
sudo ln -sfn /etc/nginx/sites-available/devimg /etc/nginx/sites-enabled/devimg
sudo nginx -t && sudo systemctl reload nginx

# 文档站证书（若尚未签发）
sudo certbot --nginx -d devimg.cn -d www.devimg.cn
```

续期：系统 `certbot.timer` 自动执行。

## 6. 日常运维速查

```bash
cd /home/ht/devimg

# 发版
pnpm deploy

# 只更新代码并热更 API（文档也重建）
pnpm deploy:pull && pnpm deploy:build && pnpm deploy:restart

# 看日志 / 状态
pnpm deploy:logs
pnpm deploy:status
pnpm deploy:health

# 停机维护
pnpm deploy:stop
```

验收 URL：

- `<https://cdn.devimg.cn/health>`
- `<https://cdn.devimg.cn/400/300>`
- `<https://devimg.cn/>`

## 7. 故障排查

| 现象 | 排查 |
| ------ | ------ |
| `https://cdn` 返回 514 | CDN「HTTPS 服务」是否开启；证书是否有效；访问控制限频 |
| CDN 回源失败 | 回源是否 HTTP:80；HOST 是否 `cdn.devimg.cn`；源站 Nginx 是否启用 |
| 文档仍显示 localhost | 是否用 `VITE_API_BASE` 执行了 `pnpm deploy:build` / `pnpm deploy` |
| 端口冲突 | API 必须用 3010，勿占用同机 3000 |
| `git pull` 冲突 | 服务器勿手改已跟踪文件；先 `git status` 再 pull |

```text
├── ecosystem.config.cjs      # PM2
├── .env.deploy.example       # 公开构建变量示例
├── nginx/

│   └── devimage.conf         # 历史参考

    ├── start.sh / stop.sh / restart.sh
    ├── status.sh / logs.sh / health.sh

```
