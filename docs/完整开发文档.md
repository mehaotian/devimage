**一句话**：国内开发者的零配置占位 CDN — 复制 URL 即可用于 `<img>`、`fetch()`，替代 picsum 国内慢的问题。

## 4. 全局约定

### 4.1 URL 设计原则

- **图片 CDN 路径不加 `/v1`**（与 picsum 一致，URL 长期稳定）
- **管理类接口**（OpenAPI、未来控制台）可使用 `/v1`
- Path 参数用 `/` 分隔；placehold 风格 `800x600` **已实现**

### 4.2 通用参数约束

| 约束项 | 规则 |
| -------- | ------ |
| 宽度 / 高度 | 整数，`10` ~ `4000` |
| 颜色 `bg` / `fg` | hex，3 位或 6 位，**不含 `#`** |
| 文字 `text` | 最长 **50** 字符，SVG 转义 |
| 名称 `name` | URL 编码，支持中文 |
| Mock `count` | 1 ~ **100**，默认 10 |
| Mock `id` | 1 ~ **100** |

### 4.3 参数别名（已实现）

| 主参数 | 兼容别名 | 状态 |
| -------- | ---------- | ------ |
| `bg` | `bc` | ✅ |
| `fg` | `tc` | ✅ |
| `text` | `t` | ✅ |
| `w` / `h`（query） | `width` / `height` | 📋 占位路由仍用 path 尺寸；query 别名未接管 |
| `bgColor` / `textColor` | — | 📋 未实现 |

### 4.4 响应头规范

| 资源类型 | Content-Type | Cache-Control |
| ---------- | -------------- | --------------- |
| 随机合成图 | `image/svg+xml; charset=utf-8` | `public, max-age=3600` |
| seed / 头像 | `image/svg+xml; charset=utf-8` | `public, max-age=31536000, immutable` |
| 场景图 | `image/svg+xml; charset=utf-8` | `public, max-age=86400` |
| 真实照片 | `image/webp` | `public, max-age=31536000, immutable` |
| Mock JSON | `application/json; charset=utf-8` | `public, max-age=300` |

### 4.5 错误响应

| HTTP | 场景 | 响应体 |
| ------ | ------ | -------- |
| `400` | 尺寸/颜色/variant 非法 | JSON `{ statusCode, message }` |
| `404` | Mock id 不存在 | JSON `{ statusCode, message }` |
| `429` | 超过限流 | JSON（Throttler 默认） |

### 4.6 限流（已上线）

| 项 | 值 |
| ---- | ----- |
| 策略 | 全局限流 `@nestjs/throttler` |
| 默认（SVG / JSON） | **1000 次 / 分钟 / IP** |
| 栅格 WebP / PNG | **60 次 / 分钟 / IP** |
| 栅格尺寸 | 单边上限 **1024**；更大请用 SVG |

### 4.7 CORS

```http
Access-Control-Allow-Origin: *
```

### 5.1 合成占位图（Placeholder）

**用途**：替代 placehold.co / 纯色块占位，国内毫秒级 SVG。

#### 5.1.1 `GET /:width/:height`

| 属性 | 说明 |
| ------ | ------ |
| **分期** | 一期 ✅ |
| **状态** | ✅ 已实现 |
| **方法** | GET |
| **响应** | SVG 图片 |

##### 5.1.1 Path 参数

| 参数 | 类型 | 必填 | 约束 | 说明 |
| ------ | ------ | ------ | ------ | ------ |
| `width` | number | 是 | 10–4000 | 图片宽度（path 段 `:w`） |
| `height` | number | 是 | 10–4000 | 图片高度（path 段 `:h`） |

##### 5.1.1 Query 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
| ------ | ------ | ------ | ------ | ------ |
| `text` | string | 否 | `{width}×{height}` | 显示文字 |
| `bg` | string | 否 | 随机灰 `#cccccc` | 背景色 hex |
| `fg` | string | 否 | `#666666` | 文字色 hex |

##### 5.1.1 行为

- 无 seed：每次请求背景色**随机**（HSL 随机 hue）
- 有 `bg`/`fg` 时忽略随机色

##### 5.1.1 示例

```html
<img src="https://cdn.devimg.cn/800/600" />
<img src="https://cdn.devimg.cn/400/300?text=Banner&bg=409eff&fg=ffffff" />
```

---

#### 5.1.2 `GET /seed/:seed/:width/:height`

| 属性 | 说明 |
| ------ | ------ |
| **分期** | 一期 ✅ |
| **状态** | ✅ 已实现 |
| **方法** | GET |
| **响应** | SVG 图片（确定性） |

##### 5.1.2 Path 参数

| 参数 | 类型 | 必填 | 说明 |
| ------ | ------ | ------ | ------ |
| `seed` | string | 是 | 任意字符串，决定配色与表现 |
| `width` | number | 是 | 10–4000 |
| `height` | number | 是 | 10–4000 |

##### 5.1.2 Query 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
| ------ | ------ | ------ | ------ | ------ |
| `text` | string | 否 | `{width}×{height}` | 显示文字 |
| `bg` | string | 否 | 由 seed 推导 | 背景色 |
| `fg` | string | 否 | 由 seed 推导 | 文字色 |

##### 5.1.2 行为

- 相同 `seed` + 相同尺寸 → **永远相同**配色（基于 seed hash → HSL）

##### 5.1.2 示例

```html
<img src="https://cdn.devimg.cn/seed/my-app/800/600" />
```

### 5.6 真实照片（Photo）

**用途**：替代 picsum.photos 随机真实照片。运行时 manifest：`apps/api/data/photo/`（**82 cat · 8132 张 · 15 scene**）。禁止同步请求 Pexels。

| 属性 | 说明 |
| ------ | ------ |
| **分期** | 二期 |
| **状态** | ✅ API 已上线；🚧 默认 `PHOTO_SERVE_MODE=local`，COS 原图与 meta 补全进行中 |
| **meta** | `photos.json` 中 `enriched_meta` **699 / 8132** |

#### 5.6.1 `GET /photo/:width/:height`

| 属性 | 说明 |
| ------ | ------ |
| **方法** | GET |
| **响应** | WebP（默认）/ JPEG / PNG |

##### 5.6.1 Query 参数

| 参数 | 类型 | 必填 | 说明 |
| ------ | ------ | ------ | ------ |
| `scene` | string | 否 | 用途 slug，如 `product`、`food`、`banner` |
| `cat` | string | 否 | 中文题材，如 `美食`；与 `scene` 指定其一即可 |
| `seed` | string | 否 | 有则固定选图；省略则随机 |
| `grayscale` | `0\|1` | 否 | 灰度 |
| `blur` | 1–10 | 否 | 模糊强度 |
| `format` | string | 否 | `webp`（默认）\| `jpeg` \| `png` |

##### 5.6.1 行为

1. 按 `scene` / `cat` / `seed` 从本地 manifest 选图
2. Sharp 裁剪到目标尺寸；命中 COS 变体缓存则复用
3. 未配置 COS 时从本地 / 已配置的 `cos_key` 读原图并直出
4. 响应头 `X-DevImage-Photo-Id` 为选中图库 id
